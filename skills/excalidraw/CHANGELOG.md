# Changelog

## 1.1.3
The Claude Code plugin is now called `agent-whiteboard` (the skill inside is still `excalidraw`); it has an icon.

## 1.1.2
Boards can be renamed: say "rename the board", or double-click its name in the local board list. Thanks for the request!

## 1.1.1
Installing now ends on the open Welcome board: the agent says what the skill can do and asks where boards should live, instead of stopping at "Ready". Clearer hints when Python or Node is too old. The local board opens with the board list collapsed (☰ to show it). "Update the skill" now updates it from GitHub without losing what the agent learned or your local fixes; nothing is checked in the background.

## 1.1.0
Learns from your hand edits (`board.py diff`), keeps its best generators per diagram type, tries two layouts when unsure, and can send a bug report to the author — only after showing it to you.
The local board only takes changes from its own page, not from other websites.
Labels in ellipses and diamonds, arrows that meet any shape, text widths that no longer clip, a clean check screenshot without editor UI, card and coin icons, named emoji.

## 1.0.0
First public release: local board or your own ExcaliDash server, setup wizard, Mermaid, 450+ icons.
